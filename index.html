Project by Team Autumn

One network.
More computing power.

Symbiote lets a lower-powered laptop use the GPU of a more capable laptop, over your local network or the internet.

Download

Built with

  • Flask
  • Python subprocess
  • HTTP requests
  • FIFO task queue

The Problem

Powerful computing shouldn't require an expensive laptop.

Many laptops struggle with GPU-intensive tasks. Upgrading hardware is expensive, while cloud computing can involve recurring costs and internet dependency.

What if you could use the GPU power of another laptop instead?

How it works

Send a task. Get the result back.

Your weaker laptop sends its code to the host over HTTP. A Flask server on the host receives it, runs it, and sends the output back. You keep working on your own laptop.

Laptops pair securely first, so only trusted machines can connect.

Control

The host stays in control.

The owner of the GPU laptop decides what to share, and when.

  • Chooses what to share
  • Chooses when to share
  • Approves every laptop that pairs

Why we built this

“My laptop can run the app, but its GPU can’t keep up.”

Older or integrated GPUs struggle with heavy work. A new laptop is expensive, and cloud services cost money and need internet. Meanwhile, another laptop nearby may have GPU power sitting idle.
